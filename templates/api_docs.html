Quick Start
# Base URL http://127.0.0.1:5000 # All write endpoints accept Content-Type: application/json # Example: list suppliers curl http://127.0.0.1:5000/api/suppliers # Example: create customer curl -X POST http://127.0.0.1:5000/api/customers \ -H "Content-Type: application/json" \ -d '{"name":"Acme Electric","type":"contractor"}' # Example: full reports with date filter curl "http://127.0.0.1:5000/api/reports/full?from=2026-01-01&to=2026-12-31"
